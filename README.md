# Packfinder

Search Minecraft modpacks and mods across sites from one page, and filter by things the sites can't search on, like how many mods a pack has.

**[Try it](https://perwds.github.io/)**

- Searches Modrinth and CurseForge, with Modrinth filters for categories, where a pack runs and open source only.
- Filters modpacks by mod count, which the sites can't do themselves: it checks a batch of results and keeps the ones that fit.
- It's one `index.html` with no build step.

CurseForge needs a key for every request. Get a free one at [console.curseforge.com](https://console.curseforge.com) and paste it into Packfinder's settings.
